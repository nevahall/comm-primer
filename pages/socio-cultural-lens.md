# How I Built This Site

This site is a small Jekyll project: Markdown files hold the page content, YAML front matter gives each page its title and URL, the shared layout supplies navigation and accessibility landmarks, and Sass defines the visual variables and reusable panels.

<section class="panel" aria-labelledby="tool-stack">
  <h2 id="tool-stack">Tool stack and layout</h2>
  <p>GitHub Pages builds the site with Jekyll and the GitHub Pages gem. The default layout keeps the header, skip link, navigation, main region, and footer consistent. The content uses short sections and panels so readers can scan an argument without losing its sequence.</p>
</section>
